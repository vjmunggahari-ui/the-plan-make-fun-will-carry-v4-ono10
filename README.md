# PriceSprint

`main.ts` (Node 22) writes one plan to `$MAKEFUN_OUTPUT_DIR/entry.txt`:
sell Shopify stores a 48-hour pricing report for $149 — top 20 products
priced against 5 rivals, with repricing moves — proven up front by a free
3-product sample. Day 1: build the template, email 50 stores, pay by
Stripe link. At a 2% close, day 1 makes $298; repeat daily and day 30
holds $1,000+. After writing, it reads the file back and checks it is
exactly the plan, 1–280 Unicode code points, and not only whitespace.
